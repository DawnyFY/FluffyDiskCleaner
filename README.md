# C 盘清理工具（DiskCleaner）

一个免安装的 Windows 磁盘清理工具。打开即自动扫描可清理项目并显示占用大小，勾选后一键永久删除。

基于 Windows 自带的 PowerShell 5.1 与 WinForms 实现，**不依赖任何运行库**，整个文件夹拷贝到其他电脑即可直接使用。

界面采用 [Miuix](https://compose-miuix-ui.github.io/miuix/) 设计风格。

> **关于纯净版**：本仓库的 `pure` 分支是**无启动动画的纯净版**——打开后直接进入界面，不播放任何启动动画。除此之外，功能、清理项、界面排版与带动画版（`main` 分支）完全一致，两者版本号同为 **v1.5.0**。本文档描述的就是这个纯净版。

## 特性

- **打开即扫描**：启动后自动统计各清理项的占用大小，并单独在后台计算耗时的系统组件清理。目录遍历按顶层分枝分片到多核并行（实测最重的系统组件库快约 2.7 倍），结果与单线程逐字节一致
- **磁盘占用可视**：左栏环形图分「已勾选可释放 / 可清理未勾选 / 其他已用 / 可用空间」四段展示系统盘占比，环心显示可清理合计；鼠标靠近任一段时该段的外径会沿半径方向鼓大（整段不平移），并以折线引出该段的名称、数值与占比
- **自由勾选**：43 个清理项按低 / 中 / 高三级风险分类，低风险默认勾选，中高风险默认不勾，避免误删
- **永久删除**：直接删除文件，不经过回收站，确保空间真正释放
- **安全兜底**：内置多路径黑名单，拒绝删除 `C:\`、`C:\Windows`、`C:\Users`、用户目录、程序自身目录等；执行前弹出确认框，高风险项额外提示
- **首次启动需同意免责声明**：第一次打开时弹出免责声明，选择「我已阅读并同意」后才会进入主界面，同意状态记入配置文件，后续启动不再打扰
- **可选自动清理**：可设为每次启动时按上次的勾选自动清理，并给出 5 秒倒计时允许中止
- **自动检测**：启动时按本机目录判定每一项是否适用，没有对应软件或目录的项不会出现在列表里（没装 Office 就没有 Office 缓存项，没升级过系统就没有 Windows.old 项）；列表右上角会显示「已隐藏 N 项」，日志里列出具体是哪些、为什么。目录存在但当前为空的项目仍会保留——它们下一轮就可能产生内容
- **便携**：配置与程序同目录，不写注册表，不打系统补丁，拷走即用

## 环境要求

- Windows 10 / 11（需 PowerShell 5.1 及以上，系统自带）
- 建议以管理员身份运行：部分系统级目录（如 Windows 更新缓存、DISM 组件清理）需要管理员权限才能操作

本工具的开发与验证环境：Windows 11 家庭版（中文）· 25H2 · 内部版本 26200 · PowerShell 5.1 · 显示缩放 125%（2560 × 1600）。**其他系统版本、系统语言与缩放比例未经完整验证**，详见 [`DISCLAIMER.md`](DISCLAIMER.md) 第二节「测试环境」。

## 使用方法

1. 双击 `RunCleaner.bat`，启动器会自动申请管理员权限
2. 首次启动会弹出免责声明，阅读后点击「我已阅读并同意」；若选择「不同意并退出」，程序会直接关闭
3. 等待扫描完成，按需勾选要清理的项目
4. 点击「开始清理」，在弹出的确认框中确认后执行

若不想使用管理员权限，可直接右键 `DiskCleaner.ps1` 选择「使用 PowerShell 运行」，此时标注「需管理员权限」的项目会无法清理。

遇到问题请先查阅 [常见问题（FAQ）](FAQ.md)；反馈问题时请使用仓库的 Issue 模板，并附上你的系统版本与 PowerShell 版本。（如果你知道的话）

## 安全说明

本工具执行的是**永久删除**，删除的文件不会进入回收站，无法通过常规手段恢复。使用前请留意：

- 「回收站」一项会清空回收站，请先确认其中没有待恢复的文件
- 「Windows.old」「系统升级残留目录」删除后将无法回退到旧版本系统
- 「系统还原点 / 卷影副本」删除后将无法回滚系统，依赖卷影副本的第三方备份也会一并失效
- 「休眠文件」删除会同时关闭「快速启动」功能
- 执行清理前程序会弹出确认框列出待删项；高风险项会额外提示
- 还原点的占用来自 VSS，**需要管理员权限才能读取**：普通权限下该行会显示「需管理员」而不是 `0 B`，以免让人误以为没有还原点。此时磁盘容量与还原点上限占比（读注册表即可）仍会照常显示

程序内置安全校验，会拒绝以下路径，避免误伤系统与自身：

```
C:\  C:\Windows  C:\Users  C:\Program Files  C:\ProgramData
当前用户目录  程序自身所在目录
```

## 配置文件

首次运行后会在程序同目录生成 `cleaner.config.json`，记录勾选状态、自动清理开关与免责声明的同意状态。删除该文件即可恢复默认设置，此时下次启动会重新弹出免责声明。

## 命令行参数

除图形界面外，程序提供若干命令行开关，便于批量执行与问题排查：

| 参数 | 用途 |
|---|---|
| `-SelfTest` | 自检删除引擎与安全校验，仅在临时目录内操作，不触碰真实数据 |
| `-Console` | 控制台模式，不显示界面；配合 `-Auto` 可直接按配置执行清理 |
| `-RenderTo <路径>` | 将界面整体渲染为 PNG，用于比对视觉样式 |
| `-BenchPaint <帧数>` | 连续重绘指定帧数并报告耗时，用于性能对比 |
| `-SnapTo <路径>` | 走真实启动流程后截图，并额外输出一张滚动后的画面 |
| `-Config <路径>` | 指定配置文件路径 |
| `-UnlockKey <密钥>` | 二改授权：跳过脚本完整性校验（密钥不随仓库发布，见下文「二改与完整性校验」） |

示例：

```powershell
# 自检（不修改任何真实数据）
powershell -ExecutionPolicy Bypass -File .\DiskCleaner.ps1 -SelfTest

# 控制台模式，按配置文件静默清理
powershell -ExecutionPolicy Bypass -File .\DiskCleaner.ps1 -Console -Auto
```
